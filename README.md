# GCC Atlas submission

Static release prepared from the sibling gcc-compass repository in the independent GCC Atlas workspace. dist/index.html opens the Atlas homepage; dist/reports.html contains research; dist/planner.html opens the planning tool; dist/deck.html is the 17-slide product deck, with its PDF in dist/deck-assets; dist/compass.html is the checked announcement record and how it was built. No dependencies, API keys or backend are needed. Saved decisions are browser-local. Non-cost city ratings and desk/overhead inputs are illustrative. The source checkout and its tests remain in gcc-compass. GitHub Pages is the public host; the separate Sites registration could not be retrieved.
